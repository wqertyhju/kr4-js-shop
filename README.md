# Kr3 Responsive Shop

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта

Адаптивная версия многостраничного HTML/CSS-сайта учебного интернет-магазина. Проект основан на структуре КР №1 и не использует CSS-фреймворки: адаптивность реализована вручную через медиазапросы, Flexbox и Grid.

## Подход к адаптивности

- Mobile First: базовые стили рассчитаны на мобильный экран, расширения добавляются через min-width;
- медиазапросы: @media (min-width: 768px) и @media (min-width: 1024px);
- css/responsive.css подключён после css/style.css на всех страницах;
- проверен корректный viewport на всех 5 страницах;
- контейнеры: width: min(100% - 32px, 1200px);
- адаптивные отступы через clamp();
- изображения: max-width: 100%, height: auto, loading="lazy", picture + srcset;
- таблица характеристик обёрнута в .table-wrapper с горизонтальной прокруткой.

## Адаптивные решения

- шапка: static на мобильном, sticky с 768px;
- навигация: колонка на мобильном, строка с 768px;
- hero-блок: одна колонка → две колонки с 768px;
- сетка карточек: 1 → 2 колонки с 768px → 3 колонки с 1024px;
- каталог: одна колонка → 260px + 1fr с 768px;
- форма заявки: одна колонка → две колонки с 768px;
- таблица: горизонтальная прокрутка на узких экранах;
- изображения: picture с srcset, loading="lazy", адаптивные размеры.

## Исправления по доступности

- у всех полей формы есть label;
- у изображений осмысленный alt;
- семантическая структура (header, nav, main, section, article, aside, footer);
- корректные заголовки страниц и разделов;
- размер интерактивных элементов не меньше 44px;
- проверка фокуса при навигации с клавиатуры.

## КР №4 — JavaScript (практика №15)

Тема КР №4: «JavaScript: интерактивность, DOM, события, формы и валидация».

### Что добавлено на практике №15

- создан репозиторий `kr4-js-shop` на основе КР №3;
- создана папка `js` и файлы `js/data.js`, `js/main.js`;
- файлы подключены через `<script defer>` на всех 5 страницах (сначала `data.js`, потом `main.js`);
- создан объект товара `product` (id, title, category, price, discountPercent, rating, isAvailable);
- написаны функции:
  - `formatPrice(price)` — форматирование цены;
  - `getDiscountValue(price, discountPercent)` — размер скидки в рублях;
  - `getFinalPrice(price, discountPercent)` — итоговая цена со скидкой;
  - `getAvailabilityStatus(isAvailable)` — статус наличия товара;
  - `getShortDescription(product)` — краткое описание товара;
- результаты работы функций выведены в консоль браузера;
- на страницу добавлен блок `<p class="js-message" aria-live="polite"></p>`, сообщение выводится безопасно через `textContent`.

### Почему не innerHTML

Пользовательские данные нельзя вставлять через `innerHTML`: это позволяет внедрить HTML/JavaScript (XSS). В проекте используется `textContent` — он вставляет данные как текст, а не как разметку.

### Как проверить

1. Открыть `index.html` в браузере.
2. F12 → Console: должны быть сообщения `data.js подключён`, `Цена: 19990 руб.`, `Итоговая цена: 17991 руб.` и т.д.
3. На странице под шапкой — «JavaScript подключён корректно.».
4. Проверить остальные страницы: скрипты подключены, ошибок в консоли нет.

## Структура JS-файлов (КР №4)

- `js/data.js` — массив товаров `products` (10 позиций, единая структура: id, title, category, price, discountPercent, rating, isAvailable);
- `js/main.js` — базовые функции: `formatPrice`, `getDiscountValue`, `getFinalPrice`, `getAvailabilityStatus`, `getShortDescription`, поиск, фильтрация, сортировка, расчёты;
- `js/catalog.js` — вывод карточек товаров в DOM, состояние каталога (`catalogState`), обработчики поиска, фильтра и сортировки, делегирование кнопок «В корзину»;
- `js/cart.js` — корзина: добавление, удаление, расчёт суммы через `reduce`, счётчик, сохранение в `localStorage`;
- `js/validation.js` — базовая валидация формы заявки, вывод ошибок на страницу, сообщение об успешной отправке.

## Самостоятельные доработки

- **Корзина**: добавление товара из каталога, удаление, отдельная страница `cart.html`.
- **Расчёт суммы корзины через `reduce`**.
- **Сохранение корзины в `localStorage`** (ключ `kr4-cart`) — корзина не теряется после перезагрузки.
- **Счётчик товаров в корзине** в шапке на всех страницах.
- **Пустое состояние корзины** («Корзина пуста.»).
- **Улучшенные карточки**: категория, цена, статус наличия, кнопка «В корзину» с `data-product-id`.
- **Пустое состояние каталога** при отсутствии результатов поиска.

## Безопасность вывода

Пользовательские данные и данные из `localStorage` выводятся через `textContent`, без `innerHTML`. Карточки создаются через `document.createElement` и `append`. Это исключает XSS при выводе данных.
